## 📌 Overview

StudentWallet AI is an AI-powered budgeting assistant designed to help students manage their money, track daily expenses, monitor budgets, and receive personalized saving recommendations.

## 🎯 Problem

Students often struggle to manage limited budgets, track everyday spending, and save money effectively.

## 💡 Solution

StudentWallet AI aims to simplify personal finance through an intelligent assistant that helps students understand their spending and make smarter financial decisions.

## ✨ Features

- 🧾 Record daily expenses.
- 💵 Set a budget.
- 📊 View spending summaries.
- 💡 Get practical saving recommendations.
- 🤖 AI-powered natural-language assistance.

*Features may vary depending on the current implementation.*

## 🛠️ Technologies

- Python
- ASI:One API
- Agentverse and Agent Chat Protocol (ACP), where implemented

## ⚙️ Setup

1. Install Python 3.10 or newer.
2. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

3. Open the project folder:

   ```bash
   cd StudentWallet-AI
   ```

4. Install dependencies:

   ```bash
   python -m pip install openai python-dotenv
   ```

5. Create a `.env` file in the project folder and add your API key:

   ```env
   ASI_ONE_API_KEY=your_api_key_here
   ```

6. Run the application:

   ```bash
   python main.py
   ```

## 🔐 Security

Never upload API keys, passwords, or `.env` files to GitHub.
